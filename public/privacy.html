MyMoney - 나만의 가계부

1. 개인정보 처리에 관한 기본 안내

MyMoney(이하 “앱”)는 사용자가 직접 수입·지출과 예산을 관리하는 개인 가계부 서비스입니다. 현재 버전은 회원가입이나 계정 로그인을 요구하지 않으며, 사용자가 입력한 가계부 기록을 앱이 실행되는 기기의 웹 저장공간(localStorage)에 보관합니다.

현재 버전에서 입력한 가계부 기록과 선택한 거래내역 사진을 별도의 MyMoney 운영 서버로 자동 업로드하거나 다른 기기와 자동 동기화하지 않습니다. 다만 앱 화면 제공 및 사진 글자 인식에 필요한 프로그램 파일을 인터넷에서 내려받을 수 있습니다.

2. 앱에서 처리하는 데이터 및 이용 목적

  • 가계부 기록: 수입·지출 금액, 날짜, 사용처·카테고리, 거래 메모, 월별 메모, 예산. 사용자의 기록 조회, 수정, 통계 계산 및 예산 관리에 사용합니다.
  • 사용자가 선택한 이미지: 카드·계좌 거래내역 스크린샷 등. 사용자가 사진 등록 기능을 실행할 때 기기 내 글자 인식 처리에 사용하고, 인식 결과를 사용자가 검토한 후 등록할 수 있게 합니다.
  • 알림 설정: 사용자가 선택한 알림 사용 여부와 시각, 마지막 알림 날짜. 중복 알림 방지 및 가계부 기록 알림에 사용합니다. 알림 권한은 선택 사항입니다.
  • 백업 및 복원 파일: 사용자가 직접 선택하거나 생성하는 JSON 파일. 데이터 백업·복원 기능에 사용합니다. 파일 생성 및 읽기는 사용자의 기기에서 수행됩니다.

3. 데이터 저장 위치 및 보유 기간

가계부 기록과 설정은 사용자가 지우거나 브라우저·앱의 사이트 데이터가 삭제될 때까지 해당 기기의 저장공간에 남아 있을 수 있습니다. 현재 버전은 별도 회원 계정 기반 서버 보관을 제공하지 않습니다.

사용자는 앱에서 개별 수입·지출·메모를 삭제할 수 있으며, 브라우저의 MyMoney 사이트 데이터 또는 설치형 웹앱의 저장 데이터를 삭제하여 해당 기기의 기록을 지울 수 있습니다. 단, 사용자가 별도로 내려받은 JSON 백업 파일은 직접 삭제해야 합니다. 앱 제거만으로 브라우저에 보관된 사이트 데이터가 항상 삭제되는 것은 아닙니다.

4. 거래내역 사진 인식 처리

사진에서 글자를 읽기 위해 Tesseract.js 기반의 기기 내 글자 인식을 사용합니다. 선택한 이미지의 분석은 사용자의 기기에서 수행하도록 구현되어 있으며, MyMoney가 사진을 별도 인식 서버로 업로드하도록 구성하지 않았습니다.

처음 인식 기능을 실행할 때 언어 모델과 실행 파일을 외부 콘텐츠 전송 네트워크(CDN)에서 다운로드할 수 있습니다. 해당 네트워크 제공자는 파일 요청 과정에서 통상적인 접속 관련 정보(예: IP 주소, 요청 시각)를 처리할 수 있습니다. 사진 속 거래 내용 자체를 CDN에 업로드하기 위한 기능은 사용하지 않습니다.

글자 인식 결과는 부정확할 수 있으므로, 사용자는 실제 거래 기록에 반영하기 전 내용을 확인하고 수정할 수 있습니다.

5. 외부 서비스 및 데이터 제공

앱의 웹 배포는 GitHub Pages를 사용하며, 사진 인식에 필요한 라이브러리·언어 데이터 등의 파일은 관련 CDN에서 제공될 수 있습니다. 이들 서비스는 웹 요청을 처리하는 과정에서 네트워크 접속 정보를 처리할 수 있습니다. 앱 운영자는 현재 버전에서 사용자의 가계부 거래 내역을 광고 목적으로 판매하거나 제3자에게 제공하는 기능을 구현하지 않았습니다.

서비스 제공자의 개인정보 관련 정보는 GitHub 개인정보 관련 안내와 jsDelivr 개인정보 안내에서 확인할 수 있습니다.

6. 보안 및 이용자 주의사항

웹사이트는 HTTPS 연결로 제공됩니다. 가계부 데이터는 브라우저의 로컬 저장소를 이용하며, 앱 자체에서 별도의 암호화 비밀번호로 기록을 보호하는 기능은 제공하지 않습니다. 공용 기기에서는 사용을 주의하고, 기기 잠금 및 정기적인 백업 파일 관리를 권장합니다.

사용자가 생성한 백업 파일에는 개인 소비 내역이 포함될 수 있습니다. 백업 파일을 다른 사람에게 공유하거나 공개 저장소에 올리지 마세요.

7. 아동 및 회원 계정

MyMoney는 어린이를 주요 대상으로 설계된 서비스가 아니며, 현재 버전에는 회원가입, 소셜 로그인, 사용자 프로필 생성 및 기기 간 클라우드 동기화 기능이 없습니다.

8. 개인정보처리방침 변경

앱의 기능, 외부 서비스 또는 데이터 처리 방식이 변경되면 실제 동작에 맞추어 이 방침을 수정하고 적용일을 갱신합니다. 향후 로그인·동기화·광고·분석 도구 등의 기능을 추가하는 경우 해당 처리 사항을 다시 안내합니다.
